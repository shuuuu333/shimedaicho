# 締め台帳

**夜のお店 1 店舗の「締め」を、毎日 3 分で終わらせるアプリ。**
レジで打った会計が、そのまま日報と給料計算につながります。

公開版: https://shuuuu333.github.io/shimedaicho/
スマホでこの URL を開き、共有ボタン →「ホーム画面に追加」でアプリとして使えます。

---

## 何をするアプリか

紙の伝票と電卓でやっていた毎日の締めを、1 本のアプリにまとめたものです。

| | やること |
|---|---|
| **レジ** | 席をタップして入店、商品をタップ、会計。カード・現金・ツケに対応 |
| **日報** | 売上・出勤・派遣・経費・締めの 5 手順。レジで打った分は自動で入る |
| **シフト** | 誰がいつ入るかを月のカレンダーで決める |
| **今月** | 売上・利益・現金の流れ。着地予測と、利益を上げる打ち手の提案 |
| **キャスト** | 時給とバック単価。本人はスマホで自分の給料を見られる |

オーナー・スタッフ・キャストで見える範囲が変わります。キャストには店の台帳は見せません。

## 作るときに決めたこと

数字が合わないアプリは使われないので、**正しさを先に固定して、そのうえで速くする**という順番で作っています。

### 計算は変えない

給料と締めの計算（`src/domain/calc.ts`）は、**ランダムに作った状態 300 件**で作り直す前のコードと
同じ結果になることを毎回確かめています。画面をいくら変えても、ここは動きません。

### 現場で止まらないこと

- 注文は **1〜2 タップ**、会計は **3 タップ**
- 金額は打たせない。選ぶだけで決まるようにする
- 紙と併用している期間があるので、**閉店後に紙から写す専用の画面**がある
- 接客中に指が滑って画面が変わらないよう、スワイプには「やらない条件」を先に決めてある

### 間違いを見つける側に回る

ただ記録するだけでなく、**合わないときに理由の候補を出す**ようにしています。

- 現金が合わないとき、差の向きと台帳の中身から原因の候補を出す
- 入れ忘れ（入店中のまま・商品 0 件・本数 0・紙の枚数ずれ）を締めで指摘する
- 取消や値引きが起きたら、その場でオーナーの LINE に流す

### 見た目も「触って速い」ために

iPhone で使う前提で、Apple が公開している値に揃えています。

- 下のタブと画面内の切り替えは**すりガラス**。指を置いてなぞると、レンズが付いてきて離した所に決まる
- 動きの曲線は SwiftUI の `interactiveSpring()`（response 0.15 / damping 0.86）を式から解いて CSS の `linear()` に焼いたもの
- 文字は Dynamic Type と同じ 10 段（11 / 12 / 13 / 15 / 16 / 17 / 20 / 22 / 28 / 34）
- 押す所は 44pt 以上

## できること

<details>
<summary>レジ</summary>

席の配置・商品・セット料金は店ごとに設定。お通しの自動投入、延長、人数変更、テーブルチャージ、消費税（部分ごとに内税／外税）。
カード手数料はお客様に請求します（率だけ設定）。ツケ（売掛）は締めで未回収として残り、もらった日に消えます。
取消は行を消さずに理由を残すので、あとから誰が何を取り消したか追えます。
**お客様に見せる明細**（キャストの名前は出さない）と、**領収書**（宛名・但し書き・インボイス登録番号・収入印紙の案内）を出せます。
</details>

<details>
<summary>締めと分析</summary>

現金の照合、カード未回収、未払い給料、精算。
月の着地予測は曜日別に伸ばします（固定費は伸ばさない）。
先月との差を「客数・客単価・時給ぶん・バック・派遣・経費…」に分解して、利益の打ち手を額の大きい順に出します。
お客様が何時に入っているかのグラフもあります。
</details>

<details>
<summary>共有とキャスト</summary>

Supabase でクラウド同期。QR コードで招待し、役割（スタッフ／キャスト）を選んで参加。
伝票は操作の履歴（op）として積むので、2 台で同じ席を触っても壊れません。片方が圏外でも、つながったときに送られます。
キャスト本人には、資産運用アプリのような画面で「今月かせいだ額・先月の同じ日との差・次のシフト」を出します。**ランキングは出しません**（下位の子が見て辞めるため）。
</details>

## 作り

React + TypeScript + Vite の PWA。端末内（IndexedDB）で完結し、クラウド同期は任意です。

```
src/domain/   計算とルール（画面に依存しない。テストはここに集中）
src/state/    Zustand のストア
src/data/     保存（Dexie）と同期（Supabase）
src/ui/       画面
supabase/     テーブルと RLS
```

- 金額は**整数のまま** `Math.floor` で扱います（金額ライブラリは入れていません）
- 取り込む他人のコードは **MIT / Apache-2.0 のみ**
- LINE のトークンなど秘密は Supabase Secrets に置き、アプリには持たせません

```bash
npm install
npm run dev      # 開発
npm test         # 254 件
npx tsc -b
npm run build
```
