# 「こうしてほしい」のフォーム

意見の送り先は Google フォーム。下のスクリプトを 1 回走らせると、
質問まで入った状態で出来上がる。手で 20 回貼らなくていい。

## 作り方

1. https://script.google.com/home/projects/create を開く
2. 出てきたエディタの中身を全部消して、下のスクリプトを貼る
3. ▶ 実行 を押す
4. 初回だけ Google が許可を聞いてくる。自分のアカウントで自分のスクリプトを
   動かすだけなので、許可して進める
   （「このアプリは確認されていません」と出たら → 詳細 → 安全でないページに移動）
5. 下の「実行ログ」に URL が 2 つ出る。**回答用の URL** のほうを使う

## 貼るもの

```javascript
function つくる() {
  const f = FormApp.create('締め台帳 — こうしてほしい');
  f.setDescription(
    '使っていて困ったこと、こうだったらいいのに、を教えてください。\n' +
    '1店舗で使うために作ったものなので、ほかのお店のやり方は分かりません。'
  );

  f.addMultipleChoiceItem()
    .setTitle('どの画面のことですか')
    .setChoiceValues(['レジ', '日報', 'シフト', '今月', 'キャスト', '設定', '全体・その他']);

  // ここだけ必須。必須が多いと途中でやめられる
  f.addParagraphTextItem()
    .setTitle('困ったこと・こうしてほしいこと')
    .setRequired(true);

  // この 2 つが後で効く。毎日使っている店の声と、見ただけの人の声は重みが違う
  f.addMultipleChoiceItem()
    .setTitle('お店の種類')
    .setChoiceValues(['キャバクラ', 'ガールズバー', 'スナック', 'コンカフェ', 'その他']);

  f.addMultipleChoiceItem()
    .setTitle('いま使っていますか')
    .setChoiceValues(['毎日使っている', 'たまに使う', '見ただけ']);

  f.addTextItem().setTitle('返事がいる場合の連絡先（任意）');

  Logger.log('▼ 回答用の URL（これをアプリに貼る）');
  Logger.log(f.getPublishedUrl());
  Logger.log('▼ 編集用の URL（自分が直すとき）');
  Logger.log(f.getEditUrl());
}
```

## そのあと

回答用の URL を渡してもらえれば、こちらで 2 か所に入れる。

- `src/domain/feedback.ts` の `FORM_URL`
- `public/lp/index.html` の `REPLACE_WITH_FORM_URL`（`hidden` も外す）

URL が空のあいだは、アプリにも紹介ページにも送り口は出ない。

## 回答の読み方

- フォームの「回答」タブでそのまま読める
- 表にしたいなら、回答タブの緑のアイコンからスプレッドシートへ
- 来たら気づけるように、回答タブの ⋮ →「新しい回答についてのメール通知」を入れておく
