## 月ごとの時給（2026-09-04）

キャストの時給を月単位で変えられるようにした。`Cast.wages` に「YYYY-MM から いくら」を並べ、
`castWageAt(cast, shop, 月)` がその月に効く時給を返す。`payOf` は日付を受け取るので、
**過去の月の給料は当時の時給のまま**動かない。キャスト画面の登録欄で時給をタップするとシートが開く。
テスト4件を追加（`calc.test.ts` の「月ごとの時給」）。

## スマホアプリとして入れられるようにする（2026-09-04）

App Store には出さず、**PWA としてホーム画面に追加**する形。iPhone は Safari の共有 →「ホーム画面に追加」、
Android は Chrome のメニュー →「アプリをインストール」。設定に案内カード（`InstallCard.tsx`）を置き、
Android では `beforeinstallprompt` を拾ってボタン1つで追加できる。すでに追加済みなら「導入済み」と出る。

| 項目 | 内容 |
|---|---|
| アイコン | アプリのグラフと同じ絵（1本の棒＋細い区切り）。`icon.svg` / 192 / 512 / maskable 512 / apple-touch-icon 180 |
| manifest | id・scope・orientation(portrait)・display_override・categories・shortcuts（今日の日報／キャスト）を追加 |
| iPhone 対応 | `apple-mobile-web-app-status-bar-style: black-translucent` ＋ `env(safe-area-inset-*)` で時計とホームバーを避ける |
| オフライン | Service Worker が16ファイルを先読み。機内モードでも起動して入力できる |

App Store / Google Play に並べる場合は Apple Developer Program（年額）と審査、Capacitor での包み込みが要る。必要になったら着手する。
